# F27SA Software Development 1 Lab 4

In this week's lab, we will build a monthly weather temperature logbook to log each month's average temperature and find out the hottest month, the coldest month, and the mean temperature over the year. 

## Program Description
The application asks users to enter the average for each month, and after the user enters the data, the application should display the result.  

### Required Specification:

Design and implement a program with the below specifications:
1.	The application should ask for the average temperature for each month and store the entered data. 
2.	The application displays the hottest month on the screen. 
3.	The application displays the coldest month on the screen. 
4.	The application should calculate the mean temperature of the year.
